# SDカードの動画をギガファイル便にアップロードする

ローカル（SDカードを挿したパソコン）で動く Claude Code / Codex に貼り付けるプロンプト。
クラウド実行のエージェントからは SD カードが見えないため、必ずローカルで実行する。

---

SD カードに入っている動画のうち、**2026年9月11日 18:00 以降に撮影されたもの**を
ギガファイル便（https://gigafile.nu/）にアップロードして、共有URLを教えてください。
内容は「平野つぼみパーティー」の撮影データです。

## 手順

### 1. SDカードを見つける
- macOS: `ls /Volumes/`
- Windows: `wmic logicaldisk get name,volumename` またはエクスプローラーでドライブ文字を確認
- Linux: `lsblk` / `ls /media/$USER/`

見つけたパスを私に報告してください。

### 2. 対象の動画を絞り込む
動画の拡張子は機材によって異なります（`.MP4` `.MOV` `.AVI` `.MTS` `.INSV` など）。
まずカード全体を調べ、**ファイル一覧（ファイル名・撮影日時・サイズ）を表で見せてください。**

撮影日時の判定は、この順で信頼できるほうを使ってください。
1. 動画のメタデータ上の作成日時（`ffprobe` が入っていれば
   `ffprobe -v quiet -show_entries format_tags=creation_time -of csv=p=0 <file>`）
2. ファイルの更新日時（mtime）。カメラは通常これを撮影時刻にする

**コピーせず、SDカード上の元ファイルの日時を見ること**（コピーすると日時が変わる場合がある）。

一覧を見せたうえで、「この N 件をアップロードします、合計 ○ GB」と確認を取ってから次へ進んでください。
日付の境界（9月11日 18:00 前後）に紛らわしいファイルがあれば、判断せず私に聞いてください。

### 3. アップロード
ギガファイル便には公式APIがないので、ブラウザを操作してください。
Playwright / Puppeteer が使えるならそれで、無ければ手順を私に指示してもらっても構いません。

- https://gigafile.nu/ を開く
- **保持期間を「100日」に設定**（初期値は7日。パーティーの共有なら長めが安全）
- **ダウンロードパスワードを設定する。** 人物が写った動画なので、URLを知っていれば
  誰でも落とせる状態にはしないこと。パスワードは私に確認してから決めてください
- ファイル入力要素にファイルを渡してアップロード（`setInputFiles` など）
- アップロードは動画サイズによっては数十分かかる。進捗を定期的に報告すること
- 完了後、**ダウンロードURL** と **設定したパスワード** を教えてください

複数ファイルある場合、ギガファイル便は「まとめてダウンロード」URLも発行できます。
個別URLとまとめURLの両方を報告してください。

### 4. 確認
アップロード後、発行されたURLをブラウザで開き、ファイル名とサイズが正しいことを確認してください。

## やらないこと
- SDカードのファイルを削除・移動・リネームしない（読み取りのみ）
- 対象期間外の動画をアップロードしない
- パスワード未設定で公開しない
- 私の確認なしにアップロードを開始しない
